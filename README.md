# 🐍 Snake Game in C

A classic **Snake Game built from scratch using C**, developed in **VS Code** with the **GCC compiler**.

This project is a beginner-friendly game development project created to strengthen my understanding of C programming, arrays, functions, loops, keyboard input, and game logic.

## 🚀 How It Works

The game continuously:

1. Draws the game board.
2. Displays the snake.
3. Checks for keyboard input.
4. Moves the snake.
5. Checks whether food has been eaten.
6. Updates the snake's length and score.
7. Checks for collisions.
8. Repeats until the game is over.
